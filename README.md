# Готовность к программе — тест команды СкалоКлуба

Страница с двумя тестами (критерии оказания услуг и программа). Результаты отправляются в Google Таблицу.

## Файлы

- `index.html` — страница теста.
- `questions.js` — банк вопросов. Под новую программу меняется только он.
- `config.js` — адрес приёмника результатов (`endpoint`).
- `apps-script.gs` — скрипт для Google Таблицы, который принимает результаты.

## Как подключить Google Таблицу (один раз, ~5 минут)

1. Создайте новую Google Таблицу, например «СкалоКлуб — тесты команды».
2. В меню таблицы: **Расширения → Apps Script**. Удалите содержимое `Code.gs`, вставьте целиком `apps-script.gs`. В строке `var SECRET = "";` впишите кодовое слово (оно живёт только здесь, в репозиторий не попадает). Сохраните (Ctrl+S).
3. Справа вверху **Начать развёртывание → Новое развёртывание**. Тип — **Веб-приложение**. Параметры:
   - Выполнять от имени: **Я**.
   - У кого есть доступ: **Все** (это нужно, чтобы страница могла отправлять результаты без входа в Google; саму таблицу никто не видит).
   Нажмите «Начать развёртывание», разрешите доступ своему аккаунту.
4. Скопируйте **URL веб-приложения** (вида `https://script.google.com/macros/s/…/exec`).
5. Вставьте его в `config.js` в поле `endpoint` (или пришлите Клоду — он обновит файл).
6. Проверка: в редакторе скрипта выберите функцию `testPost` и нажмите «Выполнить» — в таблице появятся листы «Попытки» и «Сводка» с тестовой строкой. Её можно удалить.

Если позже скрипт меняется, нужно сделать **Управление развёртываниями → карандаш → Новая версия**, иначе страница продолжит стучаться в старую.

## Кодовое слово

Страница открывается только после ввода кодового слова; оно проверяется скриптом и запоминается на устройстве. Сообщайте его команде в оргчате. Чтобы сменить: поправить `SECRET` в редакторе Apps Script и выпустить новую версию развёртывания — старое слово перестанет работать у всех.

## Что в таблице

- **Попытки** — каждая попытка строкой: дата, имя, роль, группа, тест, баллы, процент, статус, минуты, слабые блоки, список вопросов с ошибками.
- **Сводка** — по одному человеку на строку (имя сопоставляется без учёта регистра): лучший процент по критериям и по программе, статус (готов ≥ 85 %, 70–84 % пересдать, ниже — разбор), число попыток, последняя, что подтянуть.

## Публикация на GitHub Pages

Репозиторий → Settings → Pages → Source: *Deploy from a branch*, Branch: `main`, папка `/ (root)`. Через минуту страница открывается по адресу `https://<логин>.github.io/skaloklub-test/`.
